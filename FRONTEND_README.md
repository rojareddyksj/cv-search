# Semantic CV Search - Frontend Web Application

🎉 **The web application is now live!**

## Quick Start

```bash
# Start the development server
npm run dev
```

Then open: **http://localhost:3002**

---

## Features

### 1. **Upload CVs**
- Paste CV content directly into the web interface
- Automatic embedding generation using Cohere AI
- Real-time feedback during upload

### 2. **Semantic Search**
- Search for candidates using natural language queries
- Example queries:
  - "mobile developers"
  - "iOS expert"
  - "Android specialist"
  - "cross-platform engineer"
  - "backend developer"
- Get top 5 most relevant results with similarity scores

### 3. **View Results**
- See ranked results with similarity percentages
- Preview CV content
- Visual similarity bars
- Delete CVs from the database

### Backend (API Routes)

#### POST `/api/cvs` - Upload CV
```json
{
  "filename": "john_smith_ios.txt",
  "content": "CV content here..."
}
```

Response:
```json
{
  "message": "CV uploaded successfully",
  "cv": {
    "id": "cv_1234567890_abc123",
    "filename": "john_smith_ios.txt",
    "uploadedAt": "2025-10-04T13:00:00.000Z"
  }
}
```

#### POST `/api/search` - Search CVs
```json
{
  "query": "mobile developers",
  "topK": 5
}
```

Response:
```json
{
  "query": "mobile developers",
  "totalCVs": 10,
  "results": [
    {
      "cv": {
        "id": "cv_...",
        "filename": "hans_mueller_flutter.txt",
        "content": "...",
        "uploadedAt": "..."
      },
      "similarity": 0.4293
    }
  ]
}
```

#### GET `/api/cvs` - Get all CVs
```json
{
  "cvs": [...],
  "count": 10
}
```

#### DELETE `/api/cvs/[id]` - Delete CV
```json
{
  "message": "CV deleted successfully"
}
```

## How Semantic Search Works

### 1. Upload Process
```
User uploads CV
  ↓
POST /api/cvs
  ↓
Generate embedding (Cohere embed-english-v3.0)
  ↓
Save to data/cvs-db.json
  ↓
Return success
```

### 2. Search Process
```
User enters query
  ↓
POST /api/search
  ↓
Generate query embedding
  ↓
Load all CVs with embeddings
  ↓
Calculate cosine similarity for each CV
  ↓
Sort by similarity (highest first)
  ↓
Return top 5 results
```

### 3. Similarity Calculation
```typescript
function cosineSimilarity(a: number[], b: number[]): number {
  const dotProduct = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const magnitudeA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const magnitudeB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return dotProduct / (magnitudeA * magnitudeB);
}
```

## API Rate Limits

Cohere API has rate limits:
- **Free tier**: 1000 calls/month
- **Embedding**: ~1-2 seconds per request

Tips:
- Embeddings are cached (no re-computation)
- Search is fast (uses cached embeddings)
- Only upload generates new embeddings

## Troubleshooting

### Port already in use
If port 3000 is busy, Next.js will use 3002 (or next available).

### No CVs showing up
Run: `npm run import-cvs` to import existing CVs.

### Search returns no results
Make sure you have uploaded CVs first. Check the CV count badge at the top.

### Embedding fails
Check your Cohere API key in `src/lib/cohere.ts`.
